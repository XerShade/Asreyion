### Website Theme and Backend Updates
Just making a quick post to let you know that the theme and backend have been updated. While the theme has been updated, it is by no means perfect, but it will do for now.
The backend has been improved so I should be able to add more features to the website in the future. This is a work in progress and I will be adding more features to the backend in the future. 
For now I will be focusing on overhauling the theme and adding more features to the backend while I figure out the direction I want to take the website and community.

### What's next?
I will be focusing on redesigning the theme, from the ground up to be more modular so I can quickly create or adapt new features to the theme.
I will also be adding more features to the backend to make it more modular and allow for more customization.
For now I will still be using the existing code and theme for the website and community.

### Next Core Features
The following features will be added to the core of the website and community:

#### User Accounts and Profiles
- User accounts and profiles will be added to the website and community.
- Authentication will be done with OAuth 2.0 and other authentication methods.
- Linked accounts will provide additional functionality depending on what service(s) they are linked to.
- Roles and Permissions will be implemented, eventually user content may be added to the website and community based on user permissions.

#### Discord Integration
- Discord OAuth 2.0 integration will be added to the website and community.
- Discord roles will be synced with the website and community.
- Alerts and other announcements will be sent to Discord.

#### YouTube Integration
- YouTube OAuth 2.0 integration will be added to the website and community.
- My YouTube channels and content will be synced with the website and community.
- Alerts and other announcements will be sent to YouTube.

That is all for now, just wanted to post a quick update as it has been a while since the last update.
