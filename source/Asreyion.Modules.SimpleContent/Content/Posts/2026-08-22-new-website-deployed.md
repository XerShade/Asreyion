### New Website Deployment
I have not posted in the last few months because I have been working on a new website. The new website is now deployed and live! It has a fresh design, improved performance, and new features that I am excited to share with you. I will admit this took a bit longer then intended as I was also busy with health matters and other life issues but it is finally here. I will be posting more content in the coming weeks and months, so stay tuned for updates. Thank you for your patience and support!

#### New Theme
The new website features a modern and responsive design that looks great on all devices. I have also improved the navigation and layout to make it easier for visitors to find the content they are looking for. The new theme is built with accessibility in mind, ensuring that everyone can enjoy the content on the site. The new theme is also optimized for performance, with faster load times and improved SEO. It is also simpler while still retaining the colors and style I wanted for my website. I hope you enjoy the new look and feel of the site!

I am still working on the website and theme, and porting old content over to the new layout so some things may look a little janky for now, but I will be patching out the old content and systems I had as I work on the replacements for them in the future.

#### User Profiles
The new website includes user profiles, allowing visitors to create accounts and personalize their experience. While I have disabled the ability to create new accounts for now, I will be enabling this feature in the future. User profiles will allow visitors to save their favorite content, comment on posts, and interact with other users. I am excited to see how this feature will enhance the community aspect of the website.

I ultimately plan to have SSO and other features for accounts, so you can login and link with Discord, Patreon, Ko-Fi, etc. and have access to benefits if you are a supporter of my work. I will be working on this in the future, but for now, I am focusing on getting the core features of the website up and running.

#### Improved Performance
I have made significant improvements to the code base of the website, resulting in faster load times and honestly faster development time on my end. Long story short I was trying to implement old style injection code and other things as I didn't have a good understanding of how to do it properly in ASP.NET. I have started leveraging dependency injection and other modern practices to improve the performance and maintainability of the code. This has resulted in a more efficient website that is easier to update and maintain.

I will admit, I have not finished porting all of the old code over to the new architecture, but I am working on it and will continue to improve the website over time. I am committed to providing a high-quality experience for visitors and will continue to make improvements to the site. For example, this blog post and the blog system are still using the simple markdown file system I had before, but I will be moving to a database driven system in the future. This will allow for more advanced features and better performance.
