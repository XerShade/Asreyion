### New Website Under Construction
I would like to welcome everyone to the new website powered by my own custom made ASP.NET Core web application. 
Things are a little bit basic right now, but I will be adding more features as time goes by. I am actively working on development
of the website when I am not busy with other things. For more information and updates, please visit the [GitHub repository](https://github.com/XerShade/Asreyion).

### Why I Have Decided To Make My Own Website Software
I have decided to make my own website software with ASP.NET Core because I found myself struggling to implement
the features that I wanted in other platforms like WordPress. In addition to that I am not really a fan of php anymore.
I started my website development journey using it as my primary back end langauge, but as time went by I realized I was more into
languages like C#, so I am making this website using C# and ASP.NET Core.

I have found that ASP.NET Core is a very good framework for web development, and I am very happy with the results. Another problem
I used to find myself in with WordPress that because I was constantly struggling to make it work how I wanted it to work I would
also lose interest in posting content to it. I am hoping because this new website requires me to actively work on it, I will
also keep up on my content such as posts and other things.

### What Will Be Added In The Future
As I said before, I am actively working on development of the website when I am not busy with other things. I will be adding more features as time goes by.

- Integrations with my YouTube channels.
- Integrations with my GitHub.
- Integrations with my Patreon.
- Integrations with games I play.
- Integrations with other platforms like Steam, RetroAchievements, etc.
